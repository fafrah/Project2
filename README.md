# VibzCheck 

VibzCheck is a real-time collaborative music queue app where users can join or create rooms to share music. They can add songs to a shared queue, upvote or downvote certain tracks and chat inside a session.

## Tech Stack
- Flutter
- Firebase Auth
- Firestore
- Provider - State Managment
- Spotify Web API

### App Flow
1. User signs up or logs in
2. User creates or joins a session 
3. Session is opened to a shared queue
4. Users add songs, vote for tracks and chat
5. System sorts queue by vote score
6. Host device plays song on Spotify
